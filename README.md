# Olimpiadas Llinás

Colección de juegos educativos del Liceo Taller Llinás.

## Juegos

- **Biología** — abre [`Biologia/index.html`](Biologia/index.html) y selecciona grados 6.º–7.º o 8.º–11.º.
- **Lengua Castellana** — abre [`Lengua_Castellana/index.html`](Lengua_Castellana/index.html) y selecciona grados 6.º–7.º, 8.º–9.º o 10.º–11.º.
- **Historia** — abre [`Juego_Historia/index.html`](Juego_Historia/index.html).
- **Inglés** — abre [`Juego_Ingles/index.html`](Juego_Ingles/index.html).
- **Matemáticas** — abre [`Juego_matematicas/index.html`](Juego_matematicas/index.html).
- **Motor2D_Base** — prototipo base del motor 2D en [`Motor2D_Base/index.html`](Motor2D_Base/index.html).

## Ejecutar

Abre `index.html` en la raíz para elegir entre Biología y Lengua Castellana. Los juegos son páginas web estáticas; no requieren instalar dependencias. En las competencias nuevas, los bancos de preguntas se cargan al seleccionar una categoría.

## Exclusión

El proyecto **Quién quiere ser millonario** se mantiene en su propio repositorio y no forma parte de este.
