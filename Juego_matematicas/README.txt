INSTRUCCIONES DE USO - MISIÓN MATEMÁTICA

Este es un juego educativo diseñado para funcionar completamente fuera de línea. Siga estos pasos para jugar:

1. Copiar la carpeta JuegoMatematicas completa al computador.
2. Abrir el archivo index.html con Firefox ESR.
3. El juego funciona completamente sin Internet ni conexión a red.
4. Para actualizar el juego en el futuro, reemplazar toda la carpeta por la nueva versión.
5. No borrar las carpetas css, js ni assets, ya que contienen los estilos y la lógica del juego.
6. Si el sistema operativo pregunta con qué abrir el archivo index.html, elegir Firefox ESR.

NOTAS ADICIONALES:
- Todo el código está escrito usando tecnologías web estándar (HTML5, CSS3, JavaScript).
- El juego es compatible con pantallas de distintas resoluciones, siendo óptimo para 1024x768.
- Puede usar la tecla "Tab" para navegar por los botones y presionar "Enter" para seleccionar.
- Al final de la partida, puede imprimir una hoja de resultados con la opción incluida en la pantalla final.
