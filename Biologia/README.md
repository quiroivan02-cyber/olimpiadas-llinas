# Olimpiadas Llinás · Biología

Abre `index.html` en el navegador y selecciona la categoría de grado. Cada categoría carga solo su banco cuando se selecciona, para evitar procesar preguntas de otros niveles al iniciar. El juego usa JavaScript y CSS sin bibliotecas externas ni animaciones pesadas.

Los bancos están en `data/` y el código reutilizable está separado en `js/app.js` y `css/game.css`.
